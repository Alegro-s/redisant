# Бот ВК для NEXUS

## Что такое «интерактивное меню» в ВК

| Тип | Где настраивается | Что умеет |
|-----|-------------------|-----------|
| **Меню сообщества** | Настройки → Сообщения → Меню | Только **статические ссылки** (сайт, товар, чат). Это **не** сценарии бота. |
| **Клавиатура бота** | В коде: `messages.send` + параметр `keyboard` | Кнопки под полем ввода или **inline** под сообщением. Текстовые кнопки бот видит как обычные сообщения. |
| **Callback-кнопки** | `keyboard` с `type: callback` + Long Poll событие `message_event` | Настоящая «интерактивность»: нажатие **не** пишет текст в чат, бот отвечает через `messages.sendMessageEventAnswer` (snackbar, обновление сообщения и т.д.). |

В `bot.py` уже есть **нижняя клавиатура** (Привязать / Помощь / Открыть сайт) и **inline callback** («Где взять код?», «Пример команды»).

## Настройка под вашу группу

1. Создайте ключ с доступом к сообщениям: **Управление сообществом → Настройки → Работа с API → Создать ключ** (тип: пользовательский или сообщества — как у вас принято; для Long Poll нужны права на **сообщения сообщества**).

2. Включите **Long Poll API**: **Настройки → Сообщения → Настройки для бота** (или **Работа с API → Long Poll**) — создайте сервер, отметьте события:
   - **Входящее сообщение**
   - **Действие с callback-кнопкой** (для inline-меню)

3. Скопируйте `config.example.env` → `.env`, заполните `VK_GROUP_ID` (цифры из `club123` → `123`).

4. Запуск:
   ```bash
   pip install -r requirements.txt
   set -a && source .env && set +a   # Linux/macOS
   # Windows PowerShell: Get-Content .env | foreach { if ($_ -match '^([^#][^=]*)=(.*)$') { [Environment]::SetEnvironmentVariable($matches[1], $matches[2], 'Process') } }
   python bot.py
   ```

5. На сервере NEXUS в `.env` должен быть тот же **`VK_BOT_SECRET`**, что в `.env` бота.

## Проверка

- Напишите сообществу **«Помощь»** или **«Начать»** — бот пришлёт текст и клавиатуру.
- Код привязки: в приложении NEXUS → Профиль → **Код для бота ВК**, затем в чат с группой: `привязать NXxxxxxxxx`.

## Если клавиатура не появляется

- У сообщества должны быть **включены сообщения**.
- Пользователь должен написать **первым** (или бот должен отправить сообщение с `keyboard` — так и сделано в ответ на «Помощь»).
- Для **callback** обязательно включено событие **message_event** в Long Poll.
