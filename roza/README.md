# RozaGPT

**RozaGPT** (`roza/`) — локальный и серверный ИИ-ассистент для работы с кодом и документами (Companion, веб, голос, HF/Ollama/OpenAI).

Отдельный продукт от **Waypoint** (метрики) и **Lynx** (движок). В десктопе Waypoint (`d:\player\desktop`) чат «Лиза» может использовать внешний API (Timeweb); интеграция с `roza/` — по отдельному плану.

См. [`../README.md`](../README.md) · установка: `pyproject.toml`, `OBUCHENIE.md`.
