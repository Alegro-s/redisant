# ChairUp — Watch (HarmonyOS)

**Статус:** Wave 0 ✅ — каркас ArkTS.

## Открыть

1. [DevEco Studio 5+](https://developer.huawei.com/consumer/en/deveco-studio/)  
2. Open → `fit-huawei/apps/watch-harmony`  
3. Подключить часы (USB / wireless debugging)  
4. Run **entry** module

- `pages/Index.ets` — приветствие, 8 слотов (○●), кнопка «Старт»
