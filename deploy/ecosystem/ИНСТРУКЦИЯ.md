# Деплой: ПК → Timeweb S3 → VPS

## 1. Docker Hub (вход через Google)

CLI **не** принимает «Войти через Google». Нужен **Access Token**:

1. Откройте https://hub.docker.com (войдите через Google).
2. Слева **Settings → Personal access tokens** → **Generate** (Read & Write).
   (Раздела «Security» в новом интерфейсе нет — токены там же.)
3. Скопируйте `dckr_pat_...`
4. **DOCKER_USER** — имя в профиле Docker Hub (например `Alegro-s`), не email.

Файл на ПК: `deploy\ecosystem\docker.secrets`

```
DOCKER_USER=Alegro-s
DOCKER_PASS=dckr_pat_xxxxxxxx
```

На сервер скопируйте как `/opt/waypoint/docker.secrets`.

## 2. Сборка Lynx Launcher (Windows + APK) на ПК

Нужны: Flutter SDK, Android SDK (для APK).

```powershell
cd D:\PO
.\deploy\ecosystem\scripts\build-lynx-releases.ps1 -Target both -ZipSources
```

Результат: `D:\PO\releases\lynx-public\`

- `LynxLauncher.exe`
- `LynxLauncher-win-x64.zip`
- `app-release.apk`
- `lynx-launcher-sources.zip` (если `-ZipSources`)
- `manifest.json`

## 3. Загрузка на Timeweb S3

Файл `deploy\ecosystem\s3.secrets` (ключи из панели бакета):

```
AWS_ACCESS_KEY_ID=...
AWS_SECRET_ACCESS_KEY=...
```

```powershell
.\deploy\ecosystem\scripts\upload-timeweb-s3.ps1
```

Файлы попадут в бакет с префиксом `lynx/`.

Публичный URL (пример):

`https://s3.twcstorage.ru/bc39a46d-ee3d-4707-9e3f-9529afb602da/lynx/LynxLauncher.exe`

## 4. Пакет на сервер (один раз)

С ПК (PowerShell):

```powershell
scp D:\PO\deploy\ecosystem\server\deploy-all.sh root@72.56.244.26:/root/
scp D:\PO\deploy\ecosystem\docker.secrets.example root@72.56.244.26:/opt/waypoint/docker.secrets
scp D:\PO\deploy\ecosystem\smtp.env.example root@72.56.244.26:/opt/waypoint/smtp.env
scp D:\PO\deploy\ecosystem\s3.secrets.example root@72.56.244.26:/opt/waypoint/s3.secrets
```

На сервере отредактируйте секреты:

```bash
nano /opt/waypoint/docker.secrets
nano /opt/waypoint/smtp.env
nano /opt/waypoint/s3.secrets
```

Запуск:

```bash
chmod +x /root/deploy-all.sh
bash /root/deploy-all.sh 2>&1 | tee /root/deploy.log
```
