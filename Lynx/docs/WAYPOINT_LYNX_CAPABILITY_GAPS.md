# Недостающие возможности WaypointMetric / Lynx (roadmap)

Сводка для вывода на рынок как **универсального продукта** (аналитика + облако + BaaS), без опоры на 1С. Источник списка: `admin-panel/src/waypoint/waypointCatalog.ts` (`WAYPOINT_CAPABILITY_GAPS`).

1. **Managed Kubernetes** — UI, kubeconfig, namespaces, базовые чарты.
2. **Managed CDN** — origin, кэш, инвалидация из консоли.
3. **Резервное копирование** — расписания БД и объектов, self-service restore.
4. **L4/L7 балансировщики** — health-check, сертификаты, привязка к инстансам.
5. **DNS и SSL** — зоны, выпуск сертификатов, автообновление (сейчас вне продукта).
6. **Корпоративная почта** как продуктовая линия.
7. **Terraform provider** на все ресурсы платформы.
8. **Центр уведомлений** — единые каналы (email, Telegram, push) и политики подписки.
9. **Mobile SDK** и push под бренд Lynx (Android/iOS).
10. **Маркетплейс услуг «с менеджером»** — заказ из консоли, статус, оплата.
11. **Конструктор дашбордов** (drag-drop) поверх ingest и BaaS.
12. **Автогенерация документов** (PDF/DOC) из шаблонов и данных BaaS.
13. **Мультиарендность бизнес-кабинетов** — RLS, сегментация данных, белый лейбл.

Дополнительно (продуктовый слой):

- Встроенные **шаблоны отчётов** по каналам ingest (performance, smm, reputation).
- **Сценарии автоматизации** (cron + webhook + AI post-processing) без внешнего n8n.
- **SLA-мониторинг** публичных endpoint заказчика (synthetic checks).
