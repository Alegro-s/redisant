# Бета Lynx — без монетизации

На этапе **бета-тестирования** экосистема Lynx (Hub, Launcher, Cloud API, маркетплейс) работает **полностью бесплатно**.

## Политика

| Область | Бета |
|---------|------|
| Launcher / Editor | Бесплатно |
| Cloud API, проекты, каталог | Бесплатно |
| Маркетплейс: claim / download | Все пакеты из каталога — **без оплаты** |
| Billing, подписки, ₽ в UI | **Отключены** до отдельного решения о монетизации |

## Техническая реализация

- Каталог: `price: 0` или поле `price` отсутствует (`server/data/marketplace_catalog.json`, bundled JSON в `client/assets/`).
- `POST /v1/marketplace/items/{id}/claim` — выдаёт лицензию **без проверки цены** (платные SKU в JSON не блокируют claim в бете).
- Launcher: кнопки «Установить» / «Создать»; цены в рублях **не показываются** — подпись «Бесплатно (бета)».
