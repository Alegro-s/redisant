# TIC Starter

Проект с **TIC-80 API** (`spr`, `map`, `pix`, `btn`, `sfx`, `music`) и компактными редакторами в режиме «Консоль».

- Разрешение: 240×136
- Спрайт-банк: `assets/tic/sprites.bank.json` (128×128)
- Карта: `assets/tic/map.json`
- Код: `assets/scripts/game.lua`

Откройте в Engine → режим **Консоль**.
